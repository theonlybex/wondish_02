What should we ask users to calculate their prediction?

The existing dashboard formula uses 3 inputs. We can keep it lean or collect more for a richer estimate.

A

Minimal — 3 questions

Current weight → Goal weight → Weekly pace (e.g. 0.5 kg/week)

Fast to fill out. Same formula as the dashboard. Lower friction = more completions.

B

Standard — 5 questions

Current weight → Goal weight → Weekly pace → Age → Activity level

Adds TDEE-style context. Can show a more personalised number. A bit more work to fill in.

C

Full profile — 6–7 questions

Weight + goal + pace + gender + age + height + activity level

Most accurate estimate via Mifflin-St Jeor / Harris-Benedict. Higher drop-off risk on a landing page.
