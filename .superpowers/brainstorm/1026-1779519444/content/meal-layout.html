Each meal (Breakfast, Lunch, Dinner, Snack) is a clearly labelled vertical section. Dishes within a meal stack below their label. Most readable when a meal has multiple components.

B — 2×2 Quadrant Grid

Four fixed quadrants: Breakfast (top-left), Lunch (top-right), Dinner (bottom-left), Snack (bottom-right). Compact and symmetrical at a glance, but quadrants grow taller when a meal has many dishes.

C — Timeline Column

A vertical time spine (8am → 12pm → 3pm → 7pm) anchors each meal. Dishes within a meal are indented below the main. Chronologically intuitive — you read the day top to bottom.
